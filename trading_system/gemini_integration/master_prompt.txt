## 📊 MULTI-TIMEFRAME PSYCHOLOGY ENGINE

For each timeframe (LTF, MTF, HTF), calculate:

### 1. Fear Index (0–100)
Based on:
- volatility spikes (ATR increase)
- red candle dominance (consecutive down candles)
- panic volume (volume > 2x average)

### 2. Greed Index (0–100)
Based on:
- breakout strength (price > resistance)
- momentum acceleration (price acceleration rate)
- FOMO behavior (volume spike on up moves)

### 3. Trap Probability (0–100)
Based on:
- fake breakouts (wick rejection patterns)
- liquidity sweeps (price touching OI levels then reversing)
- OI divergence vs price (OI building but price falling or vice versa)

### 4. Institutional Flow Score (0–100)
Based on:
- trend alignment (all timeframes same direction)
- volume confirmation (volume supports trend)
- OI buildup direction (calls building = bullish, puts building = bearish)

---

## 🧠 MARKET STATE DETECTION

Classify market into ONE of these:

- TRENDING UP: Price > SMA20 > SMA50, higher highs/lows
- TRENDING DOWN: Price < SMA20 < SMA50, lower highs/lows
- RANGE BOUND: Price oscillating between support/resistance
- MANIPULATION / CHOP ZONE: Multiple false breakouts, trap signals high

---

## 📈 SIGNAL FUSION LOGIC

Combine all timeframes into:

### Direction Probability Calculation:
1. LTF bias = (greed_LTF - fear_LTF) / 100
2. MTF bias = (greed_MTF - fear_MTF) / 100
3. HTF bias = (greed_HTF - fear_HTF) / 100

4. Combined = (LTF * 0.3 + MTF * 0.4 + HTF * 0.3)
5. UP_Probability = 50 + (Combined * 50)
6. DOWN_Probability = 100 - UP_Probability

### Confidence Score:
- If all timeframes aligned same direction: 80-90%
- If 2 timeframes aligned: 60-75%
- If only 1 timeframe: 40-55%
- Reduce by trap_probability/100 * 30 (max 30% reduction)

### Expected Move:
- Use ATR from 1h timeframe
- Min move = (ATR / current_price) * 100 * 0.8
- Max move = (ATR / current_price) * 100 * 1.5

### Risk Level:
- LOW: trap_prob < 40%, volatility < 0.5%
- MEDIUM: trap_prob 40-70%, volatility 0.5-1.5%
- HIGH: trap_prob > 70%, volatility > 1.5%

---

## 🚨 CRITICAL RULES

### Rule 1: High Trap Detection
If Trap Probability > 70:
→ reduce confidence by 30%
→ mark signal as "⚠️ HIGH RISK - AVOID BREAKOUT TRADES"
→ suggest range trading instead

### Rule 2: Divergence Rules
If HTF trending but LTF in trap zone:
→ confidence stays medium (wait for LTF confirmation)

If LTF breakout but HTF showing rejection:
→ mark as "possible trap setup"

### Rule 3: Volume Confirmation
If trend direction has NO volume support:
→ reduce confidence by 20%
→ mark as "weak move"

### Rule 4: Never Extremes
If any score = 0 or 100:
→ cap at 5 or 95 (no extreme certainty exists)
